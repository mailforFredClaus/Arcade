12.2 The model

Save this as gpt.py. Read it against Chapter 11: Section 11.3 to 11.5 for the attention class, 11.7 for the block, 11.8 for the model.

import math
import torch
import torch.nn as nn
import torch.nn.functional as F
from dataclasses import dataclass

@dataclass
class Config:
    vocab_size: int = 65
    block_size: int = 128      # maximum context length T
    n_layer: int = 4
    n_head: int = 4
    d_model: int = 128
    dropout: float = 0.1

class CausalSelfAttention(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        assert cfg.d_model % cfg.n_head == 0
        self.n_head = cfg.n_head
        self.qkv = nn.Linear(cfg.d_model, 3 * cfg.d_model, bias=False)
        self.proj = nn.Linear(cfg.d_model, cfg.d_model)
        self.drop = nn.Dropout(cfg.dropout)
        mask = torch.tril(torch.ones(cfg.block_size, cfg.block_size, dtype=torch.bool))
        self.register_buffer("mask", mask)          # not a parameter; moves with the model

    def forward(self, x):
        B, T, d = x.shape
        q, k, v = self.qkv(x).split(d, dim=2)                       # each (B, T, d)
        heads = lambda t: t.view(B, T, self.n_head, d // self.n_head).transpose(1, 2)
        q, k, v = heads(q), heads(k), heads(v)                      # each (B, H, T, d/H)
        att = (q @ k.transpose(-2, -1)) / math.sqrt(k.size(-1))     # (B, H, T, T)
        att = att.masked_fill(~self.mask[:T, :T], float("-inf"))    # no looking ahead
        att = self.drop(F.softmax(att, dim=-1))
        y = (att @ v).transpose(1, 2).contiguous().view(B, T, d)    # merge heads
        return self.proj(y)

class Block(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.ln1 = nn.LayerNorm(cfg.d_model)
        self.attn = CausalSelfAttention(cfg)
        self.ln2 = nn.LayerNorm(cfg.d_model)
        self.mlp = nn.Sequential(
            nn.Linear(cfg.d_model, 4 * cfg.d_model),
            nn.GELU(),
            nn.Linear(4 * cfg.d_model, cfg.d_model),
            nn.Dropout(cfg.dropout),
        )

    def forward(self, x):
        x = x + self.attn(self.ln1(x))      # pre-norm residual: communicate
        x = x + self.mlp(self.ln2(x))       # pre-norm residual: compute
        return x

class GPT(nn.Module):
    def __init__(self, cfg):
        super().__init__()
        self.cfg = cfg
        self.tok_emb = nn.Embedding(cfg.vocab_size, cfg.d_model)
        self.pos_emb = nn.Embedding(cfg.block_size, cfg.d_model)
        self.drop = nn.Dropout(cfg.dropout)
        self.blocks = nn.ModuleList([Block(cfg) for _ in range(cfg.n_layer)])
        self.ln_f = nn.LayerNorm(cfg.d_model)
        self.head = nn.Linear(cfg.d_model, cfg.vocab_size, bias=False)
        self.head.weight = self.tok_emb.weight      # weight tying
        self.apply(self._init)

    def _init(self, m):
        if isinstance(m, (nn.Linear, nn.Embedding)):
            nn.init.normal_(m.weight, mean=0.0, std=0.02)
        if isinstance(m, nn.Linear) and m.bias is not None:
            nn.init.zeros_(m.bias)

    def forward(self, idx, targets=None):
        B, T = idx.shape
        pos = torch.arange(T, device=idx.device)
        x = self.drop(self.tok_emb(idx) + self.pos_emb(pos))        # (B, T, d)
        for block in self.blocks:
            x = block(x)
        logits = self.head(self.ln_f(x))                            # (B, T, V)
        loss = None
        if targets is not None:
            loss = F.cross_entropy(logits.view(B * T, -1), targets.view(B * T))
        return logits, loss

    @torch.no_grad()
    def generate(self, idx, n_new, temperature=1.0, top_k=None):
        for _ in range(n_new):
            logits, _ = self(idx[:, -self.cfg.block_size:])         # crop to the window
            logits = logits[:, -1, :] / temperature                 # last position only
            if top_k is not None:
                kth = torch.topk(logits, top_k).values[:, [-1]]
                logits = logits.masked_fill(logits < kth, float("-inf"))
            nxt = torch.multinomial(F.softmax(logits, dim=-1), num_samples=1)
            idx = torch.cat([idx, nxt], dim=1)
        return idx

Notes on the attention class.

  • One linear layer produces queries, keys, and values together, as three chunks of a 3d-wide output. This is the three projection matrices of Section 11.3 stacked.

  • The heads reshape is the whole of multi-head attention. A (B, T, d) tensor is viewed as (B, T, H, d/H) and transposed to (B, H, T, d/H). From then on the head axis behaves like a second batch axis, and every head is computed by the same matrix products.

  • The score tensor has shape (B, H, T, T). This is the quadratic term.

  • masked_fill writes minus infinity above the diagonal before the softmax, exactly as in Lab 11.

  • After the weighted sum, the transpose and view undo the head split, which concatenates the heads. proj is W_O.

Notes on the model class.

  • The position embedding is indexed by 0, ..., T − 1 and broadcasts across the batch.

  • self.head.weight = self.tok_emb.weight makes the output layer share the embedding matrix. The embedding maps token to vector; its transpose scores a vector against every token.

  • All weights start as small Gaussians with standard deviation 0.02, so the initial logits are near zero and the initial loss is near log V.

  • The loss flattens (B, T, V) logits and (B, T) targets into B·T independent classification problems. That is the per-position cross-entropy of Section 9.3.

12.3 The training script

Save as train_gpt.py.

import math, time, sys
import torch
from gpt import GPT, Config

torch.manual_seed(0)
device = "cuda" if torch.cuda.is_available() else "cpu"

# --- data: characters as tokens ---
text = open("input.txt").read()
chars = sorted(set(text))
stoi = {c: i for i, c in enumerate(chars)}
encode = lambda s: [stoi[c] for c in s]
decode = lambda ids: "".join(chars[i] for i in ids)
data = torch.tensor(encode(text))
n = int(0.9 * len(data))
train_data, val_data = data[:n], data[n:]

cfg = Config(vocab_size=len(chars))
max_steps = int(sys.argv[1]) if len(sys.argv) > 1 else 3000
batch_size, warmup, peak_lr = 32, 100, 1e-3

def get_batch(split):
    d = train_data if split == "train" else val_data
    ix = torch.randint(len(d) - cfg.block_size - 1, (batch_size,))
    x = torch.stack([d[i:i + cfg.block_size] for i in ix])
    y = torch.stack([d[i + 1:i + 1 + cfg.block_size] for i in ix])   # shifted by one
    return x.to(device), y.to(device)

@torch.no_grad()
def estimate_loss(model, n_batches=20):
    model.eval()
    out = {}
    for split in ["train", "val"]:
        out[split] = sum(model(*get_batch(split))[1].item() for _ in range(n_batches)) / n_batches
    model.train()
    return out

def lr_at(step):                               # linear warmup, then cosine decay
    if step < warmup:
        return peak_lr * (step + 1) / warmup
    progress = (step - warmup) / max(1, max_steps - warmup)
    return peak_lr * 0.5 * (1 + math.cos(math.pi * progress))

model = GPT(cfg).to(device)
print(f"{sum(p.numel() for p in model.parameters()):,} parameters")
opt = torch.optim.AdamW(model.parameters(), lr=peak_lr, betas=(0.9, 0.99), weight_decay=0.1)

t0 = time.time()
for step in range(max_steps + 1):
    if step % 500 == 0:
        l = estimate_loss(model)
        print(f"step {step:5d}  train {l['train']:.3f}  val {l['val']:.3f}  ({time.time() - t0:.0f}s)", flush=True)
    for g in opt.param_groups:
        g["lr"] = lr_at(step)
    x, y = get_batch("train")
    _, loss = model(x, y)
    opt.zero_grad(set_to_none=True)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    opt.step()

torch.save(model.state_dict(), "gpt.pt")
model.eval()
start = torch.tensor([[stoi["\n"]]], device=device)
print(decode(model.generate(start, 400, temperature=0.8, top_k=40)[0].tolist()))

Every element is something you have already met: the shifted targets (Lab 10B), AdamW (Section 6.4), warmup and cosine decay (Section 6.5), gradient clipping, and evaluation in inference mode so that dropout is off. For simplicity weight decay is applied to all parameters here; Section 6.4 notes the usual refinement.

Each batch holds 32 sequences of 128 characters, so each step trains on 4096 next-character predictions.

12.5 Checks

Before trusting a model, test it. This applies Section 7.7.

import torch
from gpt import GPT, Config

torch.manual_seed(0)
cfg = Config()
model = GPT(cfg).eval()

# 1. Parameter count against the hand calculation.
d, L, V, T = cfg.d_model, cfg.n_layer, cfg.vocab_size, cfg.block_size
per_block = 3 * d * d + (d * d + d) + (4 * d * d + 4 * d) + (4 * d * d + d) + 2 * 2 * d
by_hand = L * per_block + V * d + T * d + 2 * d
print(by_hand, sum(p.numel() for p in model.parameters()))

# 2. Causality: changing later tokens must not change earlier logits.
x = torch.randint(0, V, (1, 32))
x2 = x.clone(); x2[0, 20:] = torch.randint(0, V, (12,))
with torch.no_grad():
    a, _ = model(x); b, _ = model(x2)
print("prefix logits equal:", torch.allclose(a[0, :20], b[0, :20], atol=1e-5),
      "  later logits differ:", not torch.allclose(a[0, 20:], b[0, 20:], atol=1e-5))

# 3. Overfit one batch.
model.train()
xb = torch.randint(0, V, (4, 32)); yb = torch.randint(0, V, (4, 32))
opt = torch.optim.AdamW(model.parameters(), lr=1e-3)
for step in range(301):
    _, loss = model(xb, yb)
    opt.zero_grad(); loss.backward(); opt.step()
    if step % 100 == 0:
        print(f"step {step:3d}  loss {loss.item():.4f}")

Expected: both counts are 816512; both causality statements are True; the loss on the fixed batch falls from 4.19 to below 0.01. The third test uses random inputs and random targets, so there is nothing to learn, only to memorize, and the model memorizes 128 arbitrary input-output pairs perfectly. That it can do so shows the gradients reach every part of the network.

A fourth check is in the training log: the initial loss of 4.216 is close to log 65 = 4.174.

12.6 Experiments

Each experiment changes one thing. Run each for 1000 steps and record the validation loss beside the baseline's 1.90. Predict the outcome before you run it, and write the prediction down.

Ablations.

  1. Remove the residual connections: x = self.attn(self.ln1(x)) and likewise for the MLP.

  2. Remove both layer normalizations inside the block.

  3. Remove the position embedding.

  4. Remove the causal mask. Explain the training loss you observe, then try to generate text.

  5. Untie the input and output embeddings.

  6. Use a single head.

  7. Remove the MLP from every block, leaving attention only.

Scale.

  1. Vary the width over 32, 64, 128, and 256 at fixed depth, and the depth over 1, 2, 4, and 8 at fixed width. Plot validation loss against parameter count on a log axis. You will need this plot in Chapter 13.

  2. Vary the context length over 8, 32, and 128.

  3. Train on 10 percent of the data. Plot training and validation loss and find where they separate.

Looking inside.

  1. Return the attention weights from each head and plot them as T × T images for a passage of the play. Look for a head that attends to the previous character, and one that attends to the most recent newline or colon.

  2. Plot the position-embedding matrix, and the cosine similarity between position embeddings as a function of distance.

Engineering.

  1. Replace the character tokenizer with your BPE tokenizer from Lab 9A using 500 merges. Losses are no longer comparable per token; compare bits per character.

  2. Replace the hand-written attention arithmetic with F.scaled_dot_product_attention(q, k, v, is_causal=True) and compare speed.
