Chapter 3: Statistical Learning in One Chapter

Objectives. After this chapter you can:

  • state supervised learning as risk minimization and explain why three data splits are needed;

  • derive linear, logistic, and softmax regression from maximum likelihood;

  • implement softmax regression with gradient descent and check it numerically;

  • explain overfitting, the bias-variance decomposition, and what regularization does.

3.1 The setup

Assume inputs and targets are drawn from a fixed but unknown joint distribution p(x, y). You want a function f whose predictions incur small loss on average over that distribution. This average is the risk:

R(f) \;=\; \mathbb{E}_{(x,y)\sim p}\big[\ell(f(x),\,y)\big].

The risk cannot be computed, because p is unknown. What you have is a sample of N pairs, assumed independent and identically distributed (i.i.d.). The empirical risk replaces the expectation with the sample average, and empirical risk minimization (ERM) picks the f in your family that minimizes it. This is the training objective from Chapter 1.

The difference between risk and empirical risk at the trained model is the generalization gap. Training drives empirical risk down directly. It drives risk down only to the extent that the gap stays small.

Three splits. Because the model was chosen to do well on the training data, its training loss is a biased, optimistic estimate of risk. So data is divided three ways.

SplitUsed forWhy it must be separate
TrainingFitting parametersIt is what the optimizer sees
ValidationChoosing hyperparameters, architecture, and when to stopThose choices are also fit to data, so they need data the parameters did not see
TestOne final estimate of riskAny data used for any decision is contaminated as an estimate

The rule is strict: if you look at test performance and then change anything, the test set has become a validation set. Chapter 17 shows this failure at the scale of the whole field.

3.2 Linear regression

The simplest model is linear: f(x) = wᵀx + b. Stack the N inputs as rows of a matrix X and absorb the bias by appending a constant 1 to each input. With squared loss the objective is

L(w) \;=\; \frac{1}{2N}\,\lVert Xw - y\rVert^2, \qquad \nabla L(w) \;=\; \frac{1}{N}\,X^{\top}(Xw - y).

Setting the gradient to zero gives the normal equations XᵀX w = Xᵀy. From Chapter 2, this is also the maximum likelihood estimate when the targets are a linear function of the inputs plus Gaussian noise.

The closed form exists only because the model is linear and the loss quadratic. Gradient descent on the same objective needs only the gradient, which has the same structure in every model in this book: a matrix of inputs, transposed, times a vector of errors. Watch for that pattern.

3.3 Logistic regression

For a binary target y ∈ {0, 1}, model the probability of class 1 by squashing a linear score through the logistic sigmoid:

p(y = 1 \mid x) \;=\; \sigma(z), \qquad z = w^{\top}x + b, \qquad \sigma(z) = \frac{1}{1 + e^{-z}} .

The score z is called a logit. The likelihood of one example under this Bernoulli model is σ(z)^y (1 − σ(z))^(1−y), so the negative log-likelihood is the binary cross-entropy:

\ell(z, y) \;=\; -\,y \log \sigma(z) \;-\; (1-y)\log\big(1 - \sigma(z)\big).

Using σ′(z) = σ(z)(1 − σ(z)), the derivative collapses to something simple (Problem 3.2):

\frac{\partial \ell}{\partial z} \;=\; \sigma(z) - y, \qquad \nabla_w \ell \;=\; \big(\sigma(z) - y\big)\,x .

Prediction minus target, times input. There is no closed-form minimizer, but the objective is convex (Problem 3.3), so gradient descent finds the global minimum. The decision boundary, where σ(z) = ½, is the hyperplane wᵀx + b = 0.

3.4 Softmax regression

For K classes, compute one logit per class, z = Wx + b with W ∈ R^(K×n), and convert logits to probabilities with the softmax function:

p_k \;=\; \operatorname{softmax}(z)_k \;=\; \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}} .

The outputs are positive and sum to 1. Softmax is the smooth version of "pick the largest": the largest logit gets most of the mass, and differences between logits, not their absolute values, determine the result. Adding a constant to every logit changes nothing.

The model is a categorical distribution, so the NLL of an example with correct class c is the cross-entropy loss:

\ell(z, c) \;=\; -\log p_c \;=\; -z_c + \log\sum_{j=1}^{K} e^{z_j} .

Its gradient with respect to the logits (Problem 2.3) is

\frac{\partial \ell}{\partial z} \;=\; p - e_c , \qquad \frac{\partial \ell}{\partial W} \;=\; (p - e_c)\,x^{\top},

where e_c is the one-hot vector for class c. Once more: prediction minus target, times input. The recurrence across linear, logistic, and softmax regression is not a coincidence. All three are generalized linear models with their natural link functions, and that pairing always gives this gradient.

Why this section matters more than it looks. The output layer of every LLM is exactly softmax regression. K is the vocabulary size, x is the final hidden vector at a position, and the loss is this cross-entropy with c the token that came next. Everything before the output layer exists to produce a good x.

Numerical stability. Computing exp(z) overflows for large logits. Since softmax is invariant to shifts, subtract the maximum logit first so that the largest exponent is exp(0) = 1. For the loss, compute log-probabilities directly as z − logsumexp(z) and never take the log of a computed probability. Frameworks combine softmax and cross-entropy into one function that takes logits for this reason.

A sanity check. With zero weights every class gets probability 1/K, so the initial loss is log K. If a freshly initialized classifier does not start near log K, something is wrong. This check applies to every model in the book, including LLMs, where a new model should start near log V.

3.5 Generalization

Fit polynomials of degree 1, 3, and 15 to twenty noisy samples of a smooth curve. The line misses the shape: it underfits. The cubic tracks the curve. The degree-15 polynomial passes near every training point and oscillates wildly between them: it overfits, having spent its capacity on the noise.

Figure 3.1: the same twenty points, fitted three ways. These are actual least-squares fits. The degree-15 curve leaves the frame between data points, and its error on fresh samples is astronomically large even though its training error is the smallest of the three.

For squared loss this trade-off has an exact form. Imagine redrawing the training set many times and refitting. At a fixed test input, the expected squared error of the fitted model decomposes into three terms:

\mathbb{E}\big[(y - \hat f(x))^2\big] \;=\; \underbrace{\sigma^2}_{\text{noise}} \;+\; \underbrace{\big(\mathbb{E}[\hat f(x)] - f(x)\big)^2}_{\text{bias}^2} \;+\; \underbrace{\operatorname{Var}\big[\hat f(x)\big]}_{\text{variance}} .

Bias is error from the family being unable to represent the truth. Variance is error from the fit depending on which sample you happened to draw. Small families have high bias and low variance; large families the reverse. The classical picture is a U-shaped curve of test error against model capacity, with a best capacity in the middle.

Keep this picture, and hold it loosely. It is correct for the models of this chapter. Modern networks are trained far to the right of where the U predicts disaster, and they generalize anyway. Chapter 20 is about why.

3.6 Regularization

Regularization is anything that reduces the generalization gap, usually by restricting or penalizing the family.

L2 penalty. Add (λ/2)‖w‖² to the loss. Large weights are penalized, the fitted function becomes smoother, and variance falls at some cost in bias. For linear regression the solution becomes (XᵀX + λNI)⁻¹Xᵀy, which also cures ill-conditioning. In the singular basis of X, the penalty shrinks each component by a factor that is near 1 for directions the data constrain well and near 0 for directions it barely constrains (Problem 3.5). In gradient descent the penalty contributes λw to the gradient, so each step multiplies the weights by (1 − ηλ): hence the name weight decay.

L1 penalty. Adding λ‖w‖₁ drives many weights exactly to zero and so selects features.

Early stopping. Stop training when validation loss stops improving. For linear models trained by gradient descent from zero this behaves much like an L2 penalty, because the poorly constrained directions are the slowest to be fit.

More data. Variance falls as N grows. When more data is available it is the most reliable regularizer, which is one reason the field moved to pretraining on enormous unlabeled corpora.

3.7 Where linear models stop

A linear classifier can only draw hyperplanes. The lab below fits a three-class problem made of Gaussian blobs almost perfectly and fails on three interleaved spirals, because no set of straight boundaries separates spirals.

The classical fix is a feature map: replace x by a fixed nonlinear function φ(x), such as polynomials or radial basis functions, and fit a linear model on top. The model is then nonlinear in x and still linear in its parameters. This works when someone knows the right features. The idea of the next chapter is to make φ itself a parameterized function and learn it together with the linear model on top.

Lab 3: softmax regression from scratch

First, two synthetic datasets. Save as data.py.

import numpy as np

def make_blobs(n_per=100, k=3, seed=0):
    rng = np.random.default_rng(seed)
    angles = 2 * np.pi * np.arange(k) / k
    centers = 2.0 * np.stack([np.cos(angles), np.sin(angles)], axis=1)
    X = np.concatenate([c + 0.6 * rng.normal(size=(n_per, 2)) for c in centers])
    y = np.repeat(np.arange(k), n_per)
    return X, y

def make_spiral(n_per=100, k=3, seed=0):
    rng = np.random.default_rng(seed)
    X = np.zeros((n_per * k, 2)); y = np.zeros(n_per * k, dtype=int)
    for j in range(k):
        r = np.linspace(0.0, 1.0, n_per)
        t = np.linspace(j * 4, (j + 1) * 4, n_per) + 0.2 * rng.normal(size=n_per)
        X[j * n_per:(j + 1) * n_per] = np.c_[r * np.sin(t), r * np.cos(t)]
        y[j * n_per:(j + 1) * n_per] = j
    return X, y

Then the model. Note that the code stores examples as rows, so the weight matrix here has shape (n, K), the transpose of the W in the text.

import numpy as np
from data import make_blobs, make_spiral

def softmax(z):
    z = z - z.max(axis=1, keepdims=True)      # stability: shift so the max is 0
    e = np.exp(z)
    return e / e.sum(axis=1, keepdims=True)

def train_softmax(X, y, k, lr=0.5, steps=500, wd=1e-4):
    n, d = X.shape
    W = np.zeros((d, k)); b = np.zeros(k)
    Y = np.eye(k)[y]                          # one-hot targets, shape (n, k)
    for t in range(steps):
        P = softmax(X @ W + b)                # (n, k) predicted probabilities
        loss = -np.log(P[np.arange(n), y]).mean() + 0.5 * wd * (W ** 2).sum()
        G = (P - Y) / n                       # dL/dlogits
        W -= lr * (X.T @ G + wd * W)
        b -= lr * G.sum(axis=0)
        if t % 100 == 0:
            print(f"step {t:4d}  loss {loss:.4f}")
    return W, b

def accuracy(X, y, W, b):
    return (np.argmax(X @ W + b, axis=1) == y).mean()

for name, make in [("blobs", make_blobs), ("spiral", make_spiral)]:
    X, y = make()
    W, b = train_softmax(X, y, k=3)
    print(f"{name}: train accuracy {accuracy(X, y, W, b):.3f}\n")

Expected output: both runs start at loss 1.0986, which is log 3. The blobs reach loss 0.02 and accuracy 0.997. The spiral stalls at loss 0.735 and accuracy 0.54.
