Objectives. After this chapter you can:

  • differentiate a scalar loss with respect to a vector or matrix using differentials;

  • state the chain rule as a product of Jacobians and explain why only vector-Jacobian products are ever needed;

  • derive maximum likelihood estimators and connect them to cross-entropy and KL divergence;

  • analyze gradient descent on a quadratic and read off its stability limit and convergence rate.

This chapter is a refresher, not a first course. It selects the parts of each subject that deep learning uses daily and states them in the form the later chapters need.

#2.1 Linear algebra

Shapes. A vector x ∈ R^n is a column. A matrix W ∈ R^(m×n) is a linear map from R^n to R^m. A tensor is an array with any number of axes. In deep learning the habit that prevents most bugs is to know the shape of every quantity at every line.

Inner products and norms. The inner product xᵀy measures alignment. The Euclidean norm is ‖x‖ = sqrt(xᵀx). Cosine similarity, xᵀy / (‖x‖ ‖y‖), measures alignment independent of length and appears wherever learned vectors are compared. For matrices the Frobenius norm ‖W‖_F is the Euclidean norm of the entries, and the matching inner product is ⟨A, B⟩ = tr(AᵀB) = Σ A_ij B_ij.

Symmetric eigendecomposition. A real symmetric matrix factors as A = Q Λ Qᵀ with Q orthogonal and Λ diagonal. In the eigenbasis, A acts by scaling each coordinate independently. A is positive semidefinite when all eigenvalues are nonnegative. The condition number κ = λ_max / λ_min measures how unequal the scalings are, and Section 2.5 shows that it controls how fast gradient descent converges.

Singular value decomposition. Any matrix factors as

W=UΣV⊤=∑i=1rσi uivi⊤,σ1≥σ2≥⋯≥σr>0,W = U \Sigma V^{\top} = \sum_{i=1}^{r} \sigma_i\, u_i v_i^{\top}, \qquad \sigma_1 \ge \sigma_2 \ge \dots \ge \sigma_r > 0,

with orthonormal columns in U and V and r the rank. Geometrically, W rotates, scales along r axes, and rotates again. The Eckart–Young theorem says that truncating the sum after k terms gives the best rank-k approximation of W in Frobenius norm. This matters later: the weight updates learned in fine-tuning turn out to be well approximated at low rank, which is the basis of LoRA (Chapter 14).

Checkpoint 2.1. A matrix W ∈ R^(1000×1000) has rank 8. How many numbers are needed to store it exactly? Compare with 10^6.

#2.2 Matrix calculus

This section is the one to master. Backpropagation (Chapter 5) is nothing more than the content of this section applied repeatedly.

Gradients and Jacobians. For a scalar function L(x) of a vector x ∈ R^n, the gradient ∇L has the same shape as x and holds the partial derivatives. For a vector function y = f(x) with y ∈ R^m, the Jacobian J = ∂y/∂x is the m×n matrix with entries J_ij = ∂y_i/∂x_j. For a scalar function of a matrix W, the gradient is a matrix of the same shape as W.

Chain rule. If z = g(y) and y = f(x), the Jacobian of the composition is the product of the Jacobians:

∂z∂x  =  ∂z∂y ∂y∂x.\frac{\partial z}{\partial x} \;=\; \frac{\partial z}{\partial y}\,\frac{\partial y}{\partial x}.

The one fact that makes deep learning feasible. The final output in training is always a scalar loss L. Suppose you already know the gradient of L with respect to an intermediate vector y, call it g_y, and that y = f(x). Then

gx  =  (∂y∂x) ⁣⊤gy.g_x \;=\; \Big(\frac{\partial y}{\partial x}\Big)^{\!\top} g_y .

This is a vector-Jacobian product (VJP). You never need the Jacobian itself, only its transpose applied to one vector. For a layer with a million inputs and a million outputs the Jacobian has 10^12 entries, but the VJP usually costs about as much as evaluating the layer. Chapter 5 builds everything on this.

Differentials. The cleanest way to derive matrix gradients is to perturb the input and collect first-order terms. If you can write the change in L as

dL  =  ⟨G, dW⟩  =  tr⁡ ⁣(G⊤dW),dL \;=\; \langle G,\, dW \rangle \;=\; \operatorname{tr}\!\big(G^{\top} dW\big),

then G is the gradient of L with respect to W. Two trace identities do most of the work: tr(AB) = tr(BA), and a scalar equals its own trace.

Worked example. Let y = Wx and suppose g_y = ∂L/∂y is known. Perturb W with x fixed: dy = dW x. Then

dL=gy⊤ dy=gy⊤ dW x=tr⁡ ⁣(x gy⊤ dW)=⟨gyx⊤, dW⟩⟹∂L∂W=gy x⊤.dL = g_y^{\top}\, dy = g_y^{\top}\, dW\, x = \operatorname{tr}\!\big(x\, g_y^{\top}\, dW\big) = \big\langle g_y x^{\top},\, dW \big\rangle \quad\Longrightarrow\quad \frac{\partial L}{\partial W} = g_y\, x^{\top}.

Perturbing x with W fixed gives dy = W dx, so dL = g_yᵀ W dx and ∂L/∂x = Wᵀ g_y. Check the shapes: g_y xᵀ is m×n like W, and Wᵀ g_y is in R^n like x. If a derived gradient has the wrong shape, it is wrong.

Second order. The Hessian H = ∇²L is the symmetric matrix of second partials. The second-order Taylor expansion,

L(θ+δ)  ≈  L(θ)+∇L(θ)⊤δ+12 δ⊤H δ,L(\theta + \delta) \;\approx\; L(\theta) + \nabla L(\theta)^{\top}\delta + \tfrac{1}{2}\,\delta^{\top} H\, \delta ,

is the local model behind every analysis of optimizers in Chapter 6. The eigenvalues of H are the curvatures along its eigenvectors.

#2.3 Probability

Basics. A random variable X has a distribution p. Expectation is linear: E[aX + bY] = a E[X] + b E[Y], with no independence needed. Variance is Var[X] = E[(X − E[X])²]. For independent variables, variances add.

Joint, marginal, conditional. The joint p(x, y) factors as p(x, y) = p(y | x) p(x). Bayes' rule follows: p(y | x) = p(x | y) p(y) / p(x). Applying the factorization repeatedly gives the chain rule of probability, which holds for any distribution over sequences with no assumptions at all:

p(x1,x2,…,xT)  =  ∏t=1Tp(xt∣x1,…,xt−1).p(x_1, x_2, \dots, x_T) \;=\; \prod_{t=1}^{T} p\big(x_t \mid x_1, \dots, x_{t-1}\big).

Remember this identity. A language model is a parameterized estimate of the factors on the right.

Three distributions. The Bernoulli distribution has one parameter, the probability of a 1. The categorical distribution over K outcomes has a probability vector p with nonnegative entries summing to 1; a language model's output is a categorical distribution over the vocabulary. The Gaussian N(μ, Σ) has density proportional to exp(−½ (x − μ)ᵀ Σ⁻¹ (x − μ)).

Maximum likelihood. Given independent samples x_1, ..., x_N and a model family p(x; θ), the maximum likelihood estimate maximizes the probability the model assigns to the data. Because the log is monotone and turns products into sums, one minimizes the negative log-likelihood (NLL):

θ^MLE  =  arg⁡min⁡θ  −1N∑i=1Nlog⁡p(xi;θ).\hat\theta_{\mathrm{MLE}} \;=\; \arg\min_\theta \; -\frac{1}{N}\sum_{i=1}^{N} \log p(x_i;\theta).

Two cases recur. For a Gaussian with fixed variance and unknown mean, the NLL is the mean squared error up to constants, so least squares is maximum likelihood under Gaussian noise. For a categorical distribution, the MLE is the vector of empirical frequencies (Problem 2.5).

MAP and regularization. Placing a prior p(θ) on the parameters and maximizing the posterior adds −log p(θ) to the objective. A zero-mean Gaussian prior adds a term proportional to ‖θ‖². This is one reading of weight decay (Chapter 7).

Monte Carlo. An expectation can be estimated by averaging samples. The estimate is unbiased and its standard deviation falls as 1/sqrt(n). Minibatch training rests on this: the gradient computed on a random batch is an unbiased, noisy estimate of the gradient on the full dataset.

#2.4 Information theory

Surprisal and entropy. An event of probability p carries surprisal −log p: certain events carry none, rare events carry a lot. The entropy of a distribution is its expected surprisal,

H(p)  =  −∑xp(x) log⁡p(x).H(p) \;=\; -\sum_{x} p(x)\,\log p(x).

With log base 2 the unit is bits; with the natural log, nats. Entropy is the minimum average number of bits per symbol needed to encode draws from p. A fair coin has entropy 1 bit; a uniform distribution over K outcomes has log K.

Cross-entropy. If the data come from p but you encode them with a code designed for q, the average cost per symbol is the cross-entropy

H(p,q)  =  −∑xp(x) log⁡q(x).H(p, q) \;=\; -\sum_{x} p(x)\,\log q(x).

KL divergence. The excess cost of using the wrong distribution is

KL(p ∥ q)  =  ∑xp(x) log⁡p(x)q(x)  =  H(p,q)−H(p)  ≥  0,\mathrm{KL}(p \,\|\, q) \;=\; \sum_x p(x)\,\log\frac{p(x)}{q(x)} \;=\; H(p,q) - H(p) \;\ge\; 0,

with equality only when q = p. It is not symmetric and is not a distance.

Why this is the loss function of deep learning. Let p be the empirical distribution of the data and q_θ the model. Then H(p, q_θ) is exactly the average negative log-likelihood. Since H(p) does not depend on θ, three statements are equivalent: minimize cross-entropy, minimize KL from data to model, maximize likelihood. "Cross-entropy loss" in every framework means the NLL of a categorical model.

The coding interpretation is worth keeping in mind. A model with low cross-entropy on text is a good compressor of text, and conversely. Chapter 20 returns to what that implies.

Checkpoint 2.3. The true next-token distribution puts probability 0.5 on each of two tokens. Model A predicts (0.5, 0.5) and model B predicts (0.9, 0.1). Compute both cross-entropies in bits. Which is the entropy of the truth?

#2.5 Optimization

Gradient descent. To minimize L(θ), step against the gradient:

θk+1  =  θk−η ∇L(θk).\theta_{k+1} \;=\; \theta_k - \eta\,\nabla L(\theta_k).

The negative gradient is the direction of steepest local decrease. The learning rate η sets how far to trust that local information.

The quadratic model. Almost everything known about first-order methods can be read off the quadratic L(θ) = ½ θᵀAθ with A symmetric positive definite. Its gradient is Aθ, so gradient descent is θ ← (I − ηA)θ. In the eigenbasis of A each coordinate evolves on its own:

ei(k+1)  =  (1−ηλi)  ei(k).e_i^{(k+1)} \;=\; (1 - \eta\lambda_i)\; e_i^{(k)} .

Two conclusions follow. The iteration is stable only if |1 − ηλ_i| < 1 for every i, which requires η < 2/λ_max: the sharpest direction sets the largest usable step. With that step, the flattest direction contracts by only 1 − ηλ_min per iteration, so the number of iterations scales with the condition number κ. If you have used iterative linear solvers, this is Richardson iteration, and the same conditioning story applies.

Figure 2.1: the curves are level sets of the loss and the dots are successive iterates, computed from the update rule. The step is set just under the stability limit of the steep direction, so that coordinate flips sign every step, while the shallow coordinate shrinks by only 18 percent a step.

Near any point where the Hessian is positive definite a smooth loss looks like this quadratic, with A replaced by the Hessian. Ill-conditioning, meaning curvature that differs by orders of magnitude between directions, is the basic obstacle in neural network optimization. Momentum, Adam, normalization layers, and careful initialization are all partly treatments for it.

Non-convexity. A convex function has one basin, and gradient descent finds its minimum. Neural network losses are not convex. They have many minima and, in high dimension, far more saddle points: stationary points where the Hessian has both positive and negative eigenvalues. Chapter 6 explains why this turns out to be less of a problem than it sounds.

Why not Newton's method. Newton's method rescales the step by the inverse Hessian and removes the dependence on conditioning. With n parameters the Hessian has n² entries. For n = 10^9 that is 10^18 numbers, so the Hessian cannot be stored, let alone inverted. Deep learning uses first-order methods with cheap diagonal approximations of curvature.

#2.6 Numerical habits

Training uses 32-bit or 16-bit floats. Probabilities of long sequences underflow quickly, so work with log-probabilities and add them. Exponentials overflow, so never compute exp of a large number directly: subtract the maximum first (Chapter 3 shows this for softmax). When a quantity should be a probability, check that it is in [0, 1] and sums to 1. Most numerical bugs in this field are caught by such checks and by the gradient check below.

#Lab 2: a gradient checker

An analytic gradient can be verified against central differences, which have truncation error of order ε². You will use this tool in Chapters 3 and 5.

import numpy as np

def numerical_grad(f, x, eps=1e-6):
    """Central-difference gradient of a scalar function f at the array x."""
    g = np.zeros_like(x)
    it = np.nditer(x, flags=["multi_index"])
    for _ in it:
        i = it.multi_index
        old = x[i]
        x[i] = old + eps; f_plus = f(x)
        x[i] = old - eps; f_minus = f(x)
        x[i] = old
        g[i] = (f_plus - f_minus) / (2 * eps)
    return g

def rel_error(a, b):
    return np.abs(a - b).max() / max(1e-12, np.abs(a).max() + np.abs(b).max())

if __name__ == "__main__":
    rng = np.random.default_rng(0)
    W = rng.normal(size=(3, 4)); x = rng.normal(size=4); y = rng.normal(size=3)

    f = lambda W: 0.5 * np.sum((W @ x - y) ** 2)
    analytic = np.outer(W @ x - y, x)            # (Wx - y) x^T
    print("least squares:", rel_error(analytic, numerical_grad(f, W)))

The printed relative error is about 4e-11. Save this file as lab02_gradcheck.py; later labs import it.
