#Chapter 2

2.2. Let r = Wx − y. Then dL = rᵀ dW x = tr(x rᵀ dW), so ∂L/∂W = r xᵀ = (Wx − y)xᵀ. It has the shape of W. As an outer product it has rank 1.

2.3. With S = Σ_j exp(z_j): ∂p_i/∂z_j = δ_ij exp(z_i)/S − exp(z_i)exp(z_j)/S² = p_i(δ_ij − p_j). For L = −log p_c: ∂L/∂z_j = −(1/p_c) p_c(δ_cj − p_j) = p_j − δ_cj.

2.6. The two error components contract by |1 − η| and |1 − 100η|. The larger is minimized when they are equal: 1 − η = 100η − 1, so η = 2/101 and the factor is 99/101 ≈ 0.980. A reduction of 10^6 needs ln(10^6) / ln(101/99) ≈ 13.8 / 0.0200 ≈ 691 iterations.

#Chapter 3

3.2. With σ′ = σ(1 − σ): dℓ/dz = −y(1 − σ) + (1 − y)σ = σ − y.

3.4. For K = 2, p_1 = exp(z_1)/(exp(z_0) + exp(z_1)) = σ(z_1 − z_0), and z_1 − z_0 = (w_1 − w_0)ᵀx + (b_1 − b_0). The logistic weight vector is w_1 − w_0. Adding the same vector to every class's weights changes nothing, so softmax regression has one redundant set of parameters: K − 1 sets are free.

3.5. The stationarity condition is (XᵀX + λN I)w = Xᵀy. Substituting X = UΣVᵀ gives w = V(Σ² + λN I)⁻¹ΣUᵀy. Its component along v_i is σ_i(u_iᵀy)/(σ_i² + λN), which is the least-squares component (u_iᵀy)/σ_i multiplied by σ_i²/(σ_i² + λN).

3.7. If w separates the data, every example has a positive margin. Scaling w by c > 1 increases every margin and decreases every term of the loss, and the loss tends to 0 as c grows without reaching it. So no finite w is optimal and gradient descent increases the norm of w indefinitely. Predicted probabilities tend to 0 or 1: the model becomes certain about everything, including test points near the boundary. Regularization or early stopping prevents this.

#Chapter 4

4.1. 784 × 256 + 256 = 200,960. 256 × 128 + 128 = 32,896. 128 × 10 + 10 = 1,290. Total 235,146.

4.3. Absorb the bias into w. Let u be a unit vector with y_i uᵀx_i ≥ γ for all i, and start from w = 0. Each mistake adds y x to w. First, wᵀu grows by at least γ per mistake, so after k mistakes wᵀu ≥ kγ. Second, ‖w‖² grows by 2y wᵀx + ‖x‖², and since a mistake means y wᵀx ≤ 0, by at most R²; so ‖w‖² ≤ kR². By Cauchy-Schwarz, kγ ≤ wᵀu ≤ ‖w‖ ≤ sqrt(k) R. Hence k ≤ (R/γ)².

4.4. (a) |x| = ReLU(x) + ReLU(−x). (b) max(x₁, x₂) = x₂ + ReLU(x₁ − x₂), with x₂ = ReLU(x₂) − ReLU(−x₂): three hidden units. (c) 4[ReLU(x) − ReLU(x − ¼) − ReLU(x − ¾) + ReLU(x − 1)]. Check the slopes on each interval: 4, 0, −4, 0.

4.5. The tent map sends each half of [0, 1] linearly onto all of [0, 1]. If the k-fold composition has m pieces, each mapping onto [0, 1], then composing once more places a full copy of it on each half, giving 2m. Starting from 2 pieces, the k-fold composition has 2^k. A one-hidden-layer ReLU network with m units on a scalar input has at most m kinks and so at most m + 1 pieces. So m ≥ 2^k − 1.

#Chapter 5

5.1. Forward: u = ab = −6, v = u + c = 4, f = v² = 16. Backward: f̄ = 1, v̄ = 2v = 8, ū = 8, c̄ = 8, ā = bū = −24, b̄ = aū = 16.

5.3. z̄_j = Σ_i p̄_i ∂p_i/∂z_j = Σ_i p̄_i p_i(δ_ij − p_j) = p_j(p̄_j − pᵀp̄). For L = −log p_c, p̄ = −e_c/p_c, so pᵀp̄ = −1 and z̄_j = p_j(−δ_jc/p_c + 1) = p_j − δ_jc.

5.4. dY = dX W + X dW. So dL = tr(Ȳᵀ dX W) + tr(Ȳᵀ X dW) = tr((ȲWᵀ)ᵀ dX) + tr((XᵀȲ)ᵀ dW). Read off X̄ = ȲWᵀ, of the shape of X, and W̄ = XᵀȲ, of the shape of W.

5.6. Training must keep the activations of all L layers, about L · B · n values, more if pre-activations are stored too. Inference needs only the current layer's input and output, 2 · B · n. The ratio is L/2: 50 for L = 100.

#Chapter 6

6.2. Unrolling, m_t = (1 − β₁) Σ_(s=1..t) β₁^(t−s) g_s. Taking expectations, E[m_t] = (1 − β₁)μ Σ_(k=0..t−1) β₁^k = (1 − β₁^t)μ.

6.3. At steady state v = βv + g, so v = g/(1 − β). The step is ηg/(1 − β): an effective learning rate of η/(1 − β), ten times η for β = 0.9.

6.4. For z symmetric about zero, ReLU(z)² equals z² half the time and 0 otherwise, so E[ReLU(z)²] = ½ Var[z]. Then Var[z^(l)] = n_in σ_w² · ½ Var[z^(l−1)]. For the variance to be preserved, n_in σ_w² / 2 = 1, giving σ_w² = 2/n_in.

#Chapter 7

7.1. Normalization subtracts the mean and divides by the standard deviation, both of which scale with α, so the output is unchanged: f(αW) = f(W). Differentiating both sides with respect to W gives α ∇f(αW) = ∇f(W): the gradient at αW is 1/α times that at W. Since the function depends only on the direction of W, what matters is the step relative to ‖W‖, which scales as η/‖W‖². Weight decay shrinks ‖W‖ and therefore raises the effective learning rate of such a layer.

7.2. (I + J₃)(I + J₂)(I + J₁) = I + J₁ + J₂ + J₃ + J₂J₁ + J₃J₁ + J₃J₂ + J₃J₂J₁. Eight paths: one through no blocks, three through one, three through two, one through all three. For L blocks there are 2^L paths, with "L choose k" passing through k blocks. Most paths are of moderate length, which is why a residual network behaves somewhat like an ensemble of shallower ones.

7.5. The smoothed target is q_c = 1 − ε + ε/K on the correct class and ε/K elsewhere. Cross-entropy is minimized at p = q. The logit gap is log(q_c / (ε/K)) = log(K(1 − ε)/ε + 1). For K = 10 and ε = 0.1 it is log 91 ≈ 4.5, finite.

7.6. With He initialization, E‖ReLU(Wx)‖² = n · ½ · (2/n)‖x‖² = ‖x‖². The block outputs x + ReLU(Wx), whose mean square is ‖x‖² + ‖x‖² plus a cross term that is nonnegative once x has nonnegative entries on average. So the mean square at least doubles per block. Over 50 blocks that is a factor of at least 2^50 ≈ 10^15. The logits are astronomically large and the first updates are catastrophic.

#Chapter 8

8.1. After the first convolution: 16 × 32 × 32, since (32 + 4 − 5) + 1 = 32; parameters 16 × (3 × 25 + 1) = 1,216. After pooling: 16 × 16 × 16, no parameters. After the second convolution: 32 × 16 × 16; parameters 32 × (16 × 9 + 1) = 4,640.

8.3. Each 3 × 3 convolution at stride 1 extends the receptive field by one pixel on each side, so L of them give 2L + 1. With 2 × 2 pooling after each convolution, track the field size r and the spacing j between adjacent units in input pixels, starting from r = 1, j = 1. A convolution adds 2j to r; a pool adds j and doubles j. This gives r = 4, 10, 22, ... = 3 · 2^L − 2. Growth is exponential in depth.

#Chapter 9

9.2. Perplexity exp(1.5) ≈ 4.48. Bits per character 1.5 / ln 2 ≈ 2.16. The bigram model has perplexity 12.0, or 3.59 bits.

9.3. The log-likelihood is Σ_(a,b) C(a, b) log P(b | a), with a constraint Σ_b P(b | a) = 1 for each a. Introducing a multiplier λ_a per constraint and differentiating gives C(a, b)/P(b | a) = λ_a. Summing over b fixes λ_a = Σ_b C(a, b), so P(b | a) = C(a, b) / Σ_b′ C(a, b′).

9.4. The trigram table has V²(V − 1) ≈ 1.25 × 10^14 free parameters. The neural model: embeddings 5 × 10^6, hidden layer 200 × 500 + 500 ≈ 10^5, output layer 500 × 50,000 + 50,000 ≈ 2.5 × 10^7. Total about 3 × 10^7, some four million times fewer.

#Chapter 10

10.1. Simple RNN: h(h + d) + h. LSTM: four such maps, 4[h(h + d) + h]. PyTorch keeps two bias vectors per map, so its counts are slightly higher.

10.2. h_T = W^(T−t) h_t, so the Jacobian is W^(T−t). If W = QΛQ⁻¹ then W^k = QΛ^kQ⁻¹: the component along each eigenvector is scaled by λ_i^k. If the spectral radius is below 1 every component decays exponentially. If it is above 1 the dominant component grows exponentially. Only at exactly 1 is the signal preserved, and a generic matrix is not there.

#Chapter 11

11.1. Queries after the split: (B, H, T, d/H). Scores: (B, H, T, T). Weights: (B, H, T, T). Output before merging: (B, H, T, d/H). After merging: (B, T, d).

11.2. qᵀk = Σ_i q_i k_i. Each term has mean E[q_i]E[k_i] = 0 and variance E[q_i²]E[k_i²] = 1. The d_k terms are independent, so the variance of the sum is d_k.

11.3. Token embedding 50,257 × 768 = 38,597,376. Position embedding 1024 × 768 = 786,432. Per block: two layer norms, 3,072; attention projections 768 × 2304 + 2304 = 1,771,776 and 768 × 768 + 768 = 590,592; MLP 768 × 3072 + 3072 = 2,362,368 and 3072 × 768 + 768 = 2,360,064. That is 7,087,872 per block and 85,054,464 for twelve. Final layer norm 1,536. Total 124,439,808. The estimate 12Ld² + Vd gives 123.5 million, within one percent.

11.5. With the mask, the output at position t is a function of tokens 1 through t only. It is therefore exactly what the model would output if given that prefix alone. All T conditional distributions are valid simultaneously, and all T targets are known, so all T losses can be computed from one pass. In generation, the input at position t + 1 is the token sampled from the output at position t. It does not exist until that output has been computed and sampled, which forces one pass per token.

11.6. Rotations satisfy R(a)ᵀR(b) = R(b − a). So (R(iθ)q)ᵀ(R(jθ)k) = qᵀR(iθ)ᵀR(jθ)k = qᵀR((j − i)θ)k.

#Chapter 12

12.1. Per block: query-key-value projection 3d² = 49,152; output projection d² + d = 16,512; MLP (4d² + 4d) + (4d² + d) = 66,048 + 65,664 = 131,712; two layer norms 4d = 512. Block total 197,888; four blocks 791,552. Token embedding, shared with the output layer, 65 × 128 = 8,320. Position embedding 128 × 128 = 16,384. Final layer norm 256. Sum: 816,512.

12.3. Without the mask, position t can attend to position t + 1, which holds exactly the token it is being asked to predict. The model learns to copy it and the loss approaches zero without anything about the language being learned. At generation time there is no future token to copy, and the model has no other skill.

12.4. Per block, in units of values: attention scores and weights, 2 × B · H · T · T ≈ 4.2 million; the MLP's hidden layer before and after the activation, 2 × B · T · 4d ≈ 4.2 million; several copies of (B, T, d) tensors for the stream, its normalized versions, and queries, keys, and values, about 0.5 million each. Roughly 12 million per block, near 50 million for four blocks, or 200 megabytes in 32-bit floats. The attention matrices and the MLP hidden layer dominate, and the attention term grows quadratically with T.

13.1. 6 × 10^9 × 2 × 10^10 = 1.2 × 10^20 operations. At 10^14 per second that is 1.2 × 10^6 seconds, about 14 days.

13.2. 28 gigabytes in 32-bit, 14 in 16-bit. Training holds weights, gradients, and two Adam moments: four copies, 112 gigabytes.

13.3. C = 6N · 20N = 120N², so N = sqrt(C/120). For C = 10^24, N ≈ 9.1 × 10^10 parameters and D ≈ 1.8 × 10^12 tokens.

13.4. For a 10 percent reduction, the factor is 0.9^(−1/0.076) = exp(0.105/0.076) ≈ 4.0. To halve: 2^(1/0.076) ≈ 2^13.2 ≈ 9,000. Halving by scale alone needs four orders of magnitude. #Chapter 14

14.1. Rank 8: 8 × (4096 + 4096) = 65,536, which is 0.39 percent of 16,777,216. Rank 64: 524,288, or 3.1 percent.

14.2. With output W_0 x + sBAx and upstream gradient g, the gradients are ∂L/∂B = s g (Ax)ᵀ and ∂L/∂A = s Bᵀg xᵀ. If A and B are both zero, both gradients vanish and stay zero. With B zero and A random, B receives a gradient at once, and A does as soon as B is nonzero. Initializing both randomly would train, but it would change the model's function before any learning, disturbing the pretrained behavior.

14.3. The likelihood of an observed preference is σ(r_w − r_l). The negative log-likelihood of the dataset is the average of −log σ(r_w − r_l), which is the stated loss.

14.6. A uniform error on [−s/2, s/2] has variance s²/12. With s = 2a / 2^b, the standard deviation is a / (2^b sqrt(3)). Each added bit halves it.

#Chapter 15

15.1. Temperature 0.5 squares the probabilities: 0.25, 0.09, 0.0225, 0.0025, summing to 0.365. Normalized: 0.685, 0.247, 0.062, 0.007, in agreement with the sampled frequencies.

15.3. 2 × 32 × 8192 × 4096 = 2.15 × 10^9 values, times 2 bytes, is 4.3 × 10^9 bytes. With 8 key and value heads in place of 32, the cached width per position falls fourfold, to about 1.1 gigabytes.

15.4. Without a cache, step i processes m + i positions for i = 0, ..., n − 1, a total of nm + n(n − 1)/2. With a cache, the prompt's m positions are processed once and each later step processes one, for m + n − 1.

15.6. The most probable sequence is 100 heads, with probability 0.6^100 ≈ 6 × 10^-23. A typical sequence has about 60 heads. Each particular one is less probable than all-heads, about 6 × 10^-30, but there are about 10^28 of them, and sequences with 50 to 70 heads carry nearly all the probability. The single most probable outcome is wholly unrepresentative. Text is the same: the most probable continuation at every step yields output unlike anything typical.

15.7. The probability of emitting x is q(x) min(1, p(x)/q(x)) plus the probability of rejection times the resampling probability of x. The first term is min(q(x), p(x)). The rejection probability is 1 − Σ_y min(q(y), p(y)) = Σ_y max(0, p(y) − q(y)), which is exactly the normalizer of the resampling distribution. So the second term is max(0, p(x) − q(x)). The sum of the two terms is p(x).

#Chapter 16

16.1. 0.95^20 = 0.358. For 90 percent over 50 steps: 0.9^(1/50) = 0.9979, so 99.8 percent per step.

16.3. 10^7 × 1024 × 4 bytes ≈ 41 gigabytes. One exact search costs about 10^10 multiply-adds.

16.5. The majority is right when at least 3 of 5 are: 10(0.6³)(0.4²) + 5(0.6⁴)(0.4) + 0.6⁵ = 0.346 + 0.259 + 0.078 = 0.683. Samples from one model share its misconceptions, so their errors are positively correlated and the real gain is smaller.

#Chapter 17

17.1. sqrt(0.7 × 0.3 / 200) = 0.032. For a half-width of 0.01: 1.96 sqrt(0.21/n) = 0.01 gives n ≈ 8,100.

17.2. The variance of the mean difference is [Var(a) + Var(b) − 2 Cov(a, b)] / n. When both models find the same questions hard, the covariance is positive and the variance is smaller than the unpaired value [Var(a) + Var(b)] / n.

17.3. The expected loss is −Σ p log q = H(p) + KL(p ‖ q), which is at least H(p) with equality only when q = p. So the loss is minimized by reporting the true conditional probabilities. A model that reports true conditional probabilities is calibrated by definition: among the cases where it says 0.8, the event occurs 80 percent of the time.

#Chapter 18

18.1. 448 / 14 = 32 patches per side, 1,024 tokens. Doubling the side quadruples the token count and multiplies the cost of attention by 16.

18.2. Suppose x_(t−1) = sqrt(ᾱ_(t−1)) x_0 + sqrt(1 − ᾱ_(t−1)) ε′. Then x_t has signal coefficient sqrt(1 − β_t) sqrt(ᾱ_(t−1)) = sqrt(ᾱ_t), and its noise is the sum of two independent Gaussians with total variance (1 − β_t)(1 − ᾱ_(t−1)) + β_t = 1 − ᾱ_t.

18.4. Squared error is minimized by the conditional mean, so the optimal prediction is E[ε | x_t]. The density of x_t is the data density convolved with a Gaussian of variance 1 − ᾱ_t. Differentiating its logarithm gives the conditional expectation of −(x_t − sqrt(ᾱ_t) x_0)/(1 − ᾱ_t), which is −E[ε | x_t] / sqrt(1 − ᾱ_t). So the optimal noise prediction is the score multiplied by −sqrt(1 − ᾱ_t).

18.6. 512 × 512 × 3 = 786,432 values against 64 × 64 × 4 = 16,384: a factor of 48.

#Chapter 19

19.1. An untrained model's stream still contains the token embedding and the position embedding, which are random but fixed. The token identity is informative by itself: a newline means a count of zero, and capital letters are more common at line starts. Randomly initialized attention also averages the embeddings of earlier tokens into each position, which leaks a little about how recently a newline occurred. None of this requires learning.

19.3. The three unit directions have pairwise dot products of −½. If feature 1 alone is active, the activation is u₁: its readouts are 1, −½, −½, and after ReLU they are 1, 0, 0. Recovery is exact. If features 1 and 2 are both active, the activation is u₁ + u₂ = −u₃, with readouts ½, ½, −1, giving ½, ½, 0. The right features are identified at half strength. Interference appears only when features coincide, which is why sparsity makes superposition cheap.

19.5. With no penalty and a hidden layer at least as wide as the input, the autoencoder can copy its input exactly, for instance by using pairs of units for the positive and negative parts of each coordinate. Nothing forces the units to be meaningful. With a very large penalty every unit stays at zero and the reconstruction is a constant. An L1 penalty applies constant pressure toward zero whatever the unit's size, so small activations are driven to exactly zero, where a squared penalty would only shrink them.

#Chapter 20

20.1. The fitted coefficients are the pseudoinverse of the feature matrix applied to the targets, and noise in the targets is amplified by the reciprocal of the matrix's smallest singular value. For a random n × p matrix that value behaves like |sqrt(n) − sqrt(p)|, which is near zero when p = n. Below the threshold the system is overdetermined and noise is averaged out. Above it, additional columns move the smallest singular value away from zero again.

20.2. Each step adds a multiple of Xᵀ(Xw − y) to w, a vector in the row space of X. Starting from zero, the iterates never leave the row space. If they converge, the limit satisfies Xw = y and lies in the row space. Every solution is that one plus a vector in the null space of X, which is orthogonal to the row space, so every other solution has a larger norm.

20.4. 1.65 nats is 2.38 bits per character, so 2.38 × 10^6 bits, about 298 kilobytes, against 1 megabyte raw. The receiver also needs the model itself, or else the training procedure and an agreed ordering so that it can retrain the model in step with the sender.
