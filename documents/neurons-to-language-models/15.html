11 · The Transformer

From Neurons to Language Models·15 of 29·13 min read

Objectives. After this chapter you can:

  • write scaled dot-product attention with every shape, and justify the queries, keys, values, scaling, and mask;

  • explain self-attention, multiple heads, and how position information enters;

  • assemble a Transformer block and describe it as reads from and writes to a residual stream;

  • distinguish encoder-only, decoder-only, and encoder-decoder models;

  • count a Transformer's parameters and estimate its cost in sequence length and width.

This is the second core chapter. Chapter 12 turns it into code.

#11.1 The idea

Keep the template of Section 9.7: a vector per token, refined until it can predict the next token. Replace the recurrent contextualizer with two alternating operations.

  • Attention: each position gathers information from other positions, choosing where to look based on content.

  • A multilayer perceptron: each position processes what it gathered, independently of the others.

Stack this pair L times with residual connections and normalization. That is the Transformer (Vaswani and others, 2017). There is no recurrence and no convolution. Every position can reach every other in one step, and all positions are computed in parallel.

#11.2 Scaled dot-product attention

Attention takes three inputs. Queries Q, one row per position that is asking, of shape (T_q, d_k). Keys K, one row per position that can be looked at, of shape (T_k, d_k). Values V, one row per position that can be looked at, of shape (T_k, d_v).

Attention(Q,K,V)  =  softmax⁡ ⁣(QK⊤dk)V.\mathrm{Attention}(Q, K, V) \;=\; \operatorname{softmax}\!\left(\frac{Q K^{\top}}{\sqrt{d_k}}\right) V .

The softmax is applied to each row. Unpack it for a single query q_i:

sij=qi⊤kjdk,αij=exp⁡(sij)∑j′exp⁡(sij′),oi=∑jαij vj.s_{ij} = \frac{q_i^{\top} k_j}{\sqrt{d_k}}, \qquad \alpha_{ij} = \frac{\exp(s_{ij})}{\sum_{j'} \exp(s_{ij'})}, \qquad o_i = \sum_{j} \alpha_{ij}\, v_j .

Three steps: score every key against the query by dot product; turn the scores into weights that sum to 1; return the weighted average of the values. The output has shape (T_q, d_v).

Figure 11.1: one query against four key-value pairs. The bar lengths stand for the attention weights after the softmax. Here the second key matches best, so the output is mostly the second value.

A soft dictionary. An ordinary dictionary lookup returns the value whose key equals the query. Attention returns a blend of all values, weighted by how well each key matches. It is a lookup made differentiable. This is Bahdanau's mechanism from Section 10.7 with the learned scoring network replaced by a dot product, which is cheaper and is computed for all pairs at once by a single matrix multiplication.

Why divide by sqrt(d_k). If the entries of q and k are independent with zero mean and unit variance, their dot product has variance d_k (Problem 11.2). For d_k = 64 the raw scores would have a standard deviation of 8, and a softmax over numbers that spread out puts nearly all its mass on one entry. A saturated softmax has gradients near zero. Dividing by sqrt(d_k) keeps the scores at unit scale at initialization, so the attention starts diffuse and trainable.

#11.3 Self-attention

In self-attention the queries, keys, and values all come from the same sequence. Let X ∈ R^(T×d) hold the current vectors of the T positions. Three learned matrices project it:

Q=XWQ,K=XWK,V=XWV.Q = X W_Q, \qquad K = X W_K, \qquad V = X W_V .

Each position plays three roles through three different projections of its own vector. Its query says what it is looking for. Its key says what it contains, for the purpose of being found. Its value says what it will contribute if attended to. Separating the roles matters: what makes a token relevant to others (key) need not be the information it should hand over (value).

In the sentence "The animal didn't cross the street because it was too tired", a good representation of "it" must incorporate "animal". Self-attention can do this in one step if the query of "it" matches the key of "animal". Nothing about distance enters.

Four properties follow from the definition.

  1. Direct access. Any position can draw on any other in a single layer. The path length between any two tokens is one.

  2. Parallelism. All T outputs come from a few matrix products. Nothing is sequential.

  3. Input-dependent wiring. In a convolution, the weights that mix neighboring positions are fixed parameters. Here the mixing weights α are computed from the data. The network rewires itself for every input.

  4. No sense of order. Permute the rows of X and the outputs are permuted the same way and otherwise unchanged (Problem 11.4). Self-attention treats its input as a set. Order must be supplied separately (Section 11.6).

#11.4 The causal mask

A language model must predict token t + 1 from tokens 1 through t only. Unrestricted self-attention would let position t look at position t + 1 and copy the answer.

The fix is a causal mask. Before the softmax, set every score s_ij with j > i to minus infinity. Those positions receive weight exactly zero. Position i then attends only to positions at or before i.

Figure 11.2: the mask as a matrix. Shaded entries keep their scores. Empty entries are set to minus infinity before the softmax and so receive weight zero.

The mask has a consequence that explains much of the Transformer's success in training. Since the output at position t depends only on the prefix up to t, a single forward pass over a sequence of length T produces T valid next-token predictions at once, one per prefix. All T contribute to the loss. An RNN also yields T predictions per sequence, but it must compute them one after another. The Transformer computes them simultaneously.

At generation time the future does not exist yet, so tokens are still produced one at a time (Chapter 15).

Checkpoint 11.1. A causal self-attention layer processes a sequence of 5 tokens. Write the 5 × 5 pattern of which entries of the weight matrix α may be nonzero. What must the first row be?

#11.5 Multiple heads

A single attention operation produces one weighted average per position, and a softmax tends to concentrate on a few entries. But a token often needs several different things at once: its syntactic head, the entity it refers to, the previous token.

Multi-head attention runs H attention operations in parallel, each with its own projections into a smaller space of dimension d/H, and then concatenates the results and mixes them with one more linear map:

headh=Attention(XWQh,  XWKh,  XWVh),MHA(X)=[head1,…,headH] WO.\mathrm{head}_h = \mathrm{Attention}\big(X W_Q^{h},\; X W_K^{h},\; X W_V^{h}\big), \qquad \mathrm{MHA}(X) = \big[\mathrm{head}_1, \dots, \mathrm{head}_H\big]\, W_O .

Each head can specialize in a different relation. Because each works in d/H dimensions, the total cost and parameter count match a single head of full width: four d × d matrices in all, whatever H is.

#11.6 Position

Since self-attention ignores order, position must be injected into the representations. Three approaches are in use.

Sinusoidal encodings. The original paper adds to each token embedding a fixed vector that depends on the position, built from sines and cosines of geometrically spaced frequencies:

PE(pos, 2i)=sin⁡ ⁣(pos/100002i/d),PE(pos, 2i+1)=cos⁡ ⁣(pos/100002i/d).PE_{(pos,\,2i)} = \sin\!\big(pos / 10000^{2i/d}\big), \qquad PE_{(pos,\,2i+1)} = \cos\!\big(pos / 10000^{2i/d}\big).

Each position gets a unique pattern, and the encoding of pos + k is a fixed linear function of the encoding of pos, which makes relative offsets easy for attention to use.

Learned absolute embeddings. A table with one trainable vector per position, added to the token embedding. Simple, and used in GPT-2 and in the lab of Chapter 12. It cannot represent positions beyond the table's length.

Rotary embeddings (RoPE). Su and others (2021) apply position inside attention instead of at the input. The dimensions of each query and key are grouped into pairs, and each pair is rotated in its plane by an angle proportional to the token's position. Rotations preserve dot products up to the difference in angles, so the score between positions i and j depends on their content and on i − j only (Problem 11.6). Relative position is what language mostly cares about. RoPE or a close variant is the usual choice in current LLMs.

#11.7 The Transformer block

One block applies attention and then an MLP, each wrapped in a residual connection with layer normalization applied first:

x←x+MHA(LN(x))x←x+MLP(LN(x))\begin{aligned} x &\leftarrow x + \mathrm{MHA}\big(\mathrm{LN}(x)\big) \\ x &\leftarrow x + \mathrm{MLP}\big(\mathrm{LN}(x)\big) \end{aligned}

The MLP has one hidden layer, conventionally four times the model width, with a GELU nonlinearity, and it is applied to each position separately with the same weights:

MLP(x)  =  W2 GELU(W1x+b1)+b2,W1∈R4d×d,W2∈Rd×4d.\mathrm{MLP}(x) \;=\; W_2\,\mathrm{GELU}(W_1 x + b_1) + b_2, \qquad W_1 \in \mathbb{R}^{4d \times d}, \quad W_2 \in \mathbb{R}^{d \times 4d}.

Division of labor. Attention is the only place where positions exchange information. The MLP is where each position computes on what it has. A useful slogan: attention communicates, the MLP computes. About two thirds of a block's parameters are in the MLP.

The residual stream. Following Section 7.3, think of each position as having a d-dimensional running state. Each sublayer reads the state through a normalization and a linear map, and writes its result back by addition. Early blocks write low-level information into the stream, later blocks read it and write more abstract information. The final state at each position is the sum of the token's embedding and every sublayer's contribution.

Pre-norm and post-norm. The 2017 paper normalized after the addition, x ← LN(x + sublayer(x)). Placing the normalization before the sublayer, as above, leaves the identity path through the network completely clean, which makes deep stacks train more stably. Pre-norm is now standard. It requires one extra normalization after the last block.

#11.8 The full model

A decoder-only Transformer language model, the architecture of the GPT family and of essentially every current LLM:

  1. Token IDs, shape (B, T), index an embedding table to give vectors of shape (B, T, d). Position information is added here or inside attention.

  2. L blocks transform the vectors. The shape stays (B, T, d) throughout.

  3. A final layer normalization is applied.

  4. A linear unembedding maps each vector to V logits, shape (B, T, V). Its weight is often tied to the embedding table.

  5. Softmax over the last axis gives, at every position, a distribution over the next token.

Figure 11.3 follows a batch of B sequences of T tokens. From the embedding to the final normalization the stream keeps the shape (B, T, d); each sublayer branches off, computes, and adds its result back.

Parameter count. Ignoring biases and normalization parameters, each block has 4d² in attention and 8d² in the MLP. So

#parameters  ≈  12 L d2  +  Vd.\#\text{parameters} \;\approx\; 12\,L\,d^2 \;+\; V d .

For GPT-2 small, with L = 12, d = 768, and V = 50,257: the blocks hold 12 × 12 × 768² ≈ 85 million and the embedding 39 million, for about 124 million, which matches the published figure. The dependence on d is quadratic: doubling the width quadruples the model.

#11.9 Three families

FamilyAttentionTraining objectiveUsed for
Encoder-only (BERT)Bidirectional: every position sees every otherPredict tokens that were masked out of the inputClassification, retrieval, embeddings
Decoder-only (GPT)CausalPredict the next tokenGeneration; all current general-purpose LLMs
Encoder-decoder (the original Transformer, T5)Bidirectional encoder; causal decoder that also attends to the encoderPredict the next target token given the sourceTranslation and other input-to-output tasks

In the encoder-decoder model, the decoder has a second attention sublayer, cross-attention, whose queries come from the decoder and whose keys and values come from the encoder's output. That is Bahdanau attention exactly.

The decoder-only design won for general use. It is one stack, not two. Every token of every document is a training example. And since any task can be written as text to be continued, it needs no task-specific structure. The rest of this book concerns decoder-only models unless stated.

#11.10 Cost

For sequence length T and width d, per layer:

Layer typeComputationSequential stepsLongest path between positions
Self-attentionT² d11
RecurrentT d²TT
Convolution, kernel kk T d²1about log T

The Transformer's MLP adds T d² per layer. Two regimes follow. When T is small compared with d, the MLP and the projections dominate and cost grows linearly in T. When T is large, the T² term in attention dominates, in computation and in the memory needed to hold the T × T weights.

This quadratic growth is the reason models have a maximum context window. It is the price of direct access between all pairs of positions. Many approximations that avoid the quadratic cost have been proposed. In practice the field has mostly kept exact attention and made it efficient through careful implementation.

#11.11 Why this architecture took over

The reasons are partly established and partly judgment.

  • It parallelizes. Training throughput on GPUs is far higher than for recurrent models, so much more data can be used. This is the least glamorous reason and probably the most important.

  • Its gradients are healthy. Residual connections give every layer a direct path to the loss, and attention gives every position a direct path to every other.

  • It assumes little. As Section 8.4 argued, a weak inductive bias is a liability with little data and an asset with a lot.

  • Its routing is dynamic. Which information flows where is decided by the input, not fixed in the weights. This makes it natural to express operations like "find the earlier token that matches this one and copy what followed it", which Chapter 19 shows that trained models do learn.

#Lab 11: attention in numpy

import numpy as np

def softmax(z, axis=-1):
    z = z - z.max(axis=axis, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=axis, keepdims=True)

def attention(Q, K, V, mask=None):
    """Scaled dot-product attention.
    Q: (..., T_q, d_k)   K: (..., T_k, d_k)   V: (..., T_k, d_v)
    mask: boolean (T_q, T_k), True where attention is allowed."""
    d_k = Q.shape[-1]
    scores = Q @ np.swapaxes(K, -1, -2) / np.sqrt(d_k)     # (..., T_q, T_k)
    if mask is not None:
        scores = np.where(mask, scores, -np.inf)
    weights = softmax(scores, axis=-1)                     # rows sum to 1
    return weights @ V, weights

def self_attention(X, Wq, Wk, Wv, causal=False):
    T = X.shape[-2]
    mask = np.tril(np.ones((T, T), dtype=bool)) if causal else None
    return attention(X @ Wq, X @ Wk, X @ Wv, mask)

if __name__ == "__main__":
    rng = np.random.default_rng(0)
    T, d = 5, 8
    X = rng.normal(size=(T, d))
    Wq, Wk, Wv = (rng.normal(size=(d, d)) / np.sqrt(d) for _ in range(3))

    out, w = self_attention(X, Wq, Wk, Wv)
    print("output", out.shape, " weights", w.shape, " row sums", w.sum(-1).round(6))

    # 1. Without positions, self-attention is permutation-equivariant.
    perm = rng.permutation(T)
    out_p, _ = self_attention(X[perm], Wq, Wk, Wv)
    print("equivariant:", np.allclose(out_p, out[perm]))

    # 2. With a causal mask, position t cannot see positions after t.
    out_c, w_c = self_attention(X, Wq, Wk, Wv, causal=True)
    X2 = X.copy(); X2[3:] = rng.normal(size=(T - 3, d))    # change the future
    out_c2, _ = self_attention(X2, Wq, Wk, Wv, causal=True)
    print("causal:", np.allclose(out_c[:3], out_c2[:3]), " upper triangle zero:",
          np.allclose(np.triu(w_c, 1), 0))

Expected: shapes (5, 8) and (5, 5), row sums of 1, and True for all three tests. The two tests are worth understanding fully. The first is property 4 of Section 11.3. The second is the guarantee that makes parallel training of a language model legitimate: changing tokens 3 and 4 leaves the outputs at positions 0 through 2 untouched.
